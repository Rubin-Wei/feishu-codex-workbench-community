# Third-party components

This project uses the Codex RPC protocol and Feishu/Lark APIs. It is an independent integration, not an official product of OpenAI or Feishu.

The controller depends on httpx, lark-oapi, python-dotenv and wsproto. The web application uses React, NestJS, Drizzle, shadcn/ui-style components, Radix, Lucide, react-markdown, KaTeX and the Feishu Miaoda runtime packages. Dependencies remain subject to their respective licenses and service terms; this repository's MIT license does not relicense dependencies or grant access to hosted services.

No node_modules, Python environment, model weights, proprietary service binaries, production data or credentials are distributed. Install packages from their registries and create your own platform application. The web scaffolding targets Miaoda's runtime conventions and requires that platform for deployment.
