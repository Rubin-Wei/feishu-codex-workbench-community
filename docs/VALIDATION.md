# 验证与已知边界

社区首版来源于已运行的工作台代码，公开仓库移除了部署者身份、具体机器与测试会话记录。此文不会把维护者部署的成功当作任意新环境已验证。

- Python 测试覆盖所有者校验、任务互斥、队列 FIFO、崩溃不重放、引导的轮次校验、原生 socket 连接、历史分页、输出去重、缓存同步和文件边界。
- 新增测试覆盖 Codex 账户和周额度读取、授权会话内文件预览、路径与凭据拒绝、结果大小限制，以及网页文件链接识别。
- 网页经过 TypeScript、ESLint、Stylelint 和生产构建检查。
- 发布前的实际部署验证过输出增量、队列完成后接续、直接引导与排队转引导；手机视口验证过文字入口与消息去重。新功能在维护者实例验证过账户查询和文件预览的控制器到网页命令往返，以及本机文件读取。
- 未在所有 Codex 历史版本上测试。缺失 socket、模型不可用、原生协议或数据库异常可能导致相应功能不可用。
- 周限额仅在 Codex 返回七天额度窗口时显示；API Key 不提供这个周限额。文件预览要求会话元数据能提供工作目录，且目标在该机器配置的目录内。
- 原生数据库异常只暂停相关操作，不自动修库、迁移、启动另一版服务或重发不确定任务。能读取缓存不代表原生客户端已恢复。
- 「停止本轮」中断 Codex 轮次，不保证取消它已提交到集群调度器的训练任务。
- 不支持完整桌面工具 UI、手机附件上传、多租户或完整 W&B 面板；可以回传图片。
- 控制器的 Supervisor 保活不能替代宿主机/容器平台的启动配置。

新使用者必须按部署说明对自己的 SSH、原生 RPC、模型调用和飞书网页逐层验收。
